# Richardson step sizes for massive MIMO detection from the eigenvalue spectrum

Authors: Dhruv Aggarwal, Mohd. Rehan Ghazi, Ajay Kaushik.

`code/` simulation code (`mpopt.py` step-size design, `sim*.py` simulators). `data/` saved results (JSON) for finite-size designs, compute and latency, BER, stability, learned steps and large iteration counts.

Requirements: Python 3.11 with numpy, scipy, torch and matplotlib. Random seeds are fixed in the scripts. Large arrays are regenerated by the code and are not stored.
